Powerful Capabilities

Engineered for Flawless Campus Connectivity

Say goodbye to broken captive portal tabs, random session timeouts, and manual logins across classes and hostels.

🚀

Zero-Touch Auto-Connect

Automatically identifies PES campus Wi-Fi networks (EC Campus, RR Campus, Amaatra Hostel, and CIE) and authenticates your account in milliseconds.

🔄

Continuous 120s Keepalive

Maintains an active background keepalive daemon every 120 seconds with ±30s jitter. Keeps your captive session alive indefinitely without battery drain.

📶

Smart Strongest AP Roaming

Scans campus BSSIDs and prioritizes the access point with the highest signal strength (RSSI) so you always stay connected to the fastest nearby node.

🌐

Dynamic Gateway Discovery

Autodetects whether you are on the standard campus gateway (192.168.254.1) or the Amaatra hostel portal (192.168.1.1) with seamless fallback.

🔐

AES-256 Vault

Multiple student accounts encrypted using Android Jetpack Security with hardware-backed MasterKey keys in the Android Keystore.

📊

Live Telemetry & Diagnostics

Monitor session uptime, latency ping times, keepalive status, and live logcat directly within the app for transparent network troubleshooting.

📱

Quick Settings Tile

Add the PESU WiFi tile directly to your Android notification shade for instant one-tap login and logout without opening the app.

📳

Haptic & Material 3 UI

Clean, native Jetpack Compose interface with dynamic Material You color matching and crisp tactile feedback on every action.

🛡️

Privacy First, Open Source

No third-party analytics, no tracking, and no external telemetry. All requests communicate strictly with internal campus gateways.

Quick Start

Setup in Less Than 60 Seconds

Follow these quick steps to get connected and configure background keepalive on your device.

1

Download & Install

Grab the latest APK release from GitHub. Enable "Install Unknown Apps" for your browser when prompted.

2

Grant Permissions

Allow Notifications (for the foreground keepalive service) and Location/Nearby Wi-Fi devices (for campus AP scanning).

3

Add Account

Enter your PES University PRN (e.g. PES1UG...) and captive portal password. Credentials are encrypted on-device.

4

Tap Connect

Tap Connect & Login. The app turns on Wi-Fi, locks onto the strongest campus AP, logs in, and engages keepalive automatically.

⚡ OEM Battery Optimization Tips

Aggressive battery managers can kill background services. To ensure 120s keepalive stays active across campus walks, exclude PESU WiFi from battery restrictions:

Xiaomi / MIUI / HyperOS

Settings → Apps → Manage Apps → PESU WiFi → Battery Saver → No Restrictions. Also enable Autostart.

OnePlus / OxygenOS

Settings → Battery → Battery Optimization → PESU WiFi → Select Don't Optimize.

Samsung / One UI

Settings → Battery & device care → Battery → Background usage limits → Add to Never sleeping apps.

RealMe / OPPO (ColorOS)

Settings → App Management → PESU WiFi → Battery Usage → Allow Background Activity & Auto-launch.

Google Pixel / Stock AOSP

Settings → Apps → PESU WiFi → App battery usage → Select Unrestricted.

Campus Notice: Keepalive runs every 120 seconds with random ±30s jitter to mirror natural activity and avoid synchronised gateway packet surges. It operates as an ongoing foreground service with an active status icon in your status bar.

Specifications

Technical Architecture

Designed following modern Android best practices, Clean Architecture, and strict security standards.

Minimum OS Android 10.0 (API Level 29)
Target SDK Android 15.0 (API Level 35)
Architecture MVVM + Repository Pattern + Kotlin Coroutines & Flow
UI Toolkit 100% Jetpack Compose with Material Design 3
Encryption Jetpack Security EncryptedSharedPreferences (AES-256 GCM) backed by Android Keystore
Networking OkHttp 4.12 with dynamic gateway probing & captive portal redirect resolution
Background Execution Foreground Service (START_STICKY) + AlarmManager for 120s ±30s jittered keepalive
Supported Networks PESU-EC-Campus, PESU-RR-Campus, AMAATRA-HOSTEL, PESU-CIE, and campus affiliate APs
